# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-01

## Context

Decisions made in meetings and chat threads get lost. Newcomers then either follow rules they don't understand or
change things without knowing why they were done that way.

## Decision

We record significant decisions as Architecture Decision Records in `docs/adr`, in the format described by Michael
Nygard, reviewed through pull requests like code.

## Consequences

Writing an ADR takes an hour; it saves many more in repeated discussions. ADRs are kept short and are never edited
after acceptance, only superseded.
